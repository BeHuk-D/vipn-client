# ViPN Landing — экспериментальный редизайн

Отдельная песочница: текущий лендинг в `../` не изменялся. Здесь живёт новая визуальная система и оба экрана — главная и `/downloads/`.

## Идея

Направление — **«Сигнал»**: монохромный технический журнал, где продукт показан крупно и честно. Никаких цветных акцентов, градиентных кнопок и стоковых иллюстраций: только белый, чёрный, тёплый серый, крупная типографика, тонкие линии и один живой элемент — реальный пинг из браузера.

Ключевые приёмы:

- контрастные чёрные полосы (шаги, панель загрузки, футер) делят длинную страницу на главы;
- огромный контурный заголовок и контурный знак `ViPN` в футере;
- макет приложения ViPN на первом экране: реальный скриншот приложения и живой пинг;
- bento-сетка возможностей вместо одинаковых текстовых колонок;
- тариф «Максимум» вынесен вперёд инвертированной карточкой;
- бегущая строка сервисов и технические mono-подписи как связующий слой.

## Палитра

| Токен | Светлая тема | Тёмная тема |
| --- | --- | --- |
| `--bg` | `#f4f4f1` | `#0a0a0a` |
| `--bg-elev` / `--card` | `#ffffff` | `#111110` |
| `--fg` | `#0a0a0a` | `#f4f4f0` |
| `--muted` | `#6d6d67` | `#a2a29b` |
| `--line` | `#ddddd7` | `#272725` |
| `--inv-bg` | `#0a0a0a` | `#f2f2ed` |
| `--inv-fg` | `#f6f6f2` | `#0a0a0a` |

Цветов ровно два плюс оттенки серого. Тёмная тема включается автоматически по `prefers-color-scheme`; инверсные секции меняются местами, поэтому контраст сохраняется.

## Типографика

- **Unbounded** — заголовки, цифры, логотип. Крупные кегли с отрицательным трекингом (`-0.045em`).
- **Golos Text** — основной текст.
- **JetBrains Mono** — технические подписи, номера, файлы, статусы.

## Запуск

```bash
cd experimental-new-design
npm install
npm run dev
```

Открыть `http://localhost:5173/`; страница загрузок — `http://localhost:5173/downloads/`.

Если родительский `vipn-landing/node_modules` уже установлен, можно не выполнять `npm install`, а запустить Vite напрямую:

```bash
../node_modules/.bin/vite --port 5175
```

Сборка:

```bash
npm run build
npm run preview
```

## Поведение

- Живой пинг: несколько запросов к `https://217.60.94.172/ping`, медиана выводится в макете телефона.
- Переключение RU/EN сохраняется в `localStorage`, обновляет `<html lang>` и `document.title`.
- Мобильное меню: закрытие по Escape, блокировка скролла, ссылки и CTA.
- Липкий CTA внизу на мобильных появляется после первого экрана.
- Появление секций на скролле; при `prefers-reduced-motion` всё показывается сразу, бегущая строка останавливается.
- Страница загрузок читает `/downloads/releases.json`, группирует файлы по Linux / Windows / Android; без манифеста показывает имена файлов и ссылку в Telegram.

## Что учесть при переносе

- Ссылки `/account/` и `/downloads/` рассчитаны на продовые маршруты воркера.
- Значения в макете (трафик, дата подписки, скорость) — демонстрационные.
- Шрифты подключены с Google Fonts, как и в текущем лендинге; при желании их стоит self-host'ить.
- Перед переносом проверить Safari/Firefox: контурный текст и `backdrop-filter` — самые чувствительные места.
